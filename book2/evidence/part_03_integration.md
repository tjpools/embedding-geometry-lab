## Terminology Audit

- **score** remains query-key compatibility before normalization
- **attention weight** remains a normalized coefficient, distinct from value content, causal contribution, and semantic explanation
- **direct path** remains a property of the declared dependency graph, not measured latency
- **head** remains one projected attention channel inside multi-head composition
- **Transformer block** remains an ordered assembly of attention, residual, normalization, and feed-forward interfaces
- **specification** remains a declared implementation target rather than an executable artifact
- **framework operation** remains reusable implementation behavior, distinct from model parameters
- **package** remains structured metadata and parameters, distinct from an in-memory callable
- **runtime capability** remains a declared execution service, not a performance result
- **callable** means that a validated request can cross a declared interface and produce a declared response

## Boundary Audit

Part III does not claim:

- that attention weights establish causal importance or semantic meaning
- that graph path length predicts latency, throughput, or hardware efficiency
- that one head or one block is a complete Transformer system
- that fixed parameters are trained or production-equivalent
- that a component-removal control proves universal model causality
- that deterministic JSON is a production model-package standard
- that SHA-256 establishes semantic correctness, provenance, or trust
- that one successful invocation establishes interoperability, quality, or ecosystem reliability
- that Chapter 12 performs tokenization, decoding, or complete token-through-machine inference
- that the operational fixtures settle Chapter 16's limits or Book Three's philosophical questions
