## Features

- Configurable metrics suite for any domain
- Curvature and stability indices (e.g., Chapter Curvature Index, Stability Score)
- Drift Log: Tracks metric changes and revision history over time
- Markdown summary tables and heatmap visualizations

## Usage

Run the toolkit to update metrics and visualizations:

```bash
python chapter_metrics_suite.py
```

## Output

- `chapters_metrics.md`: Markdown table of metrics for all units
- `*_wordcount.txt` or `*_metrics.txt`: Metric logs for each unit
- `heatmap.png`: Visual heatmap of metric density
- `chapter_coherence_audit.md`: Chapter-by-chapter coherence and cohesion audit snapshot for the current manuscript

## Advanced Metrics

- **Curvature Index:** Measures density/complexity (e.g., sentences per paragraph, problems per topic)
- **Stability Score:** Tracks consolidation or volatility of knowledge
- **Drift Log:** Logs metric changes and revision dates for each unit
