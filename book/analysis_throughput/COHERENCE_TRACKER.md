# Coherence Tracker & Learning Manifold Toolkit

This toolkit generalizes the concept of a chapter metrics suite to any modular, evolving body of knowledge. It enables tracking, visualizing, and analyzing the structure and growth of understanding in any domain—books, research, learning, programming, and more.

## Key Concepts
- **Unit:** Any conceptual module (chapter, topic, project, skill, etc.)
- **Metric:** Any measurable property (word count, problems solved, vocabulary, diagrams, etc.)
- **Curvature Index:** Density/complexity measure (e.g., sentences per paragraph)
- **Stability Score:** Tracks consolidation or volatility
- **Drift Log:** Logs metric changes and revision dates for each unit

## Example Use Cases
- Math student tracking notes, problems, proofs, and stability per concept
- Language learner tracking vocabulary, sentences, conversations, and topic stability
- Researcher tracking paper sections, citations, and revision history
- Programmer tracking code modules, test coverage, and refactoring events

## Usage
- Configure the toolkit for your domain by setting unit prefixes/suffixes and defining metrics
- Run the metrics suite to generate summary tables, drift logs, and visualizations

## Philosophy
Treat any evolving knowledge system as a manifold. Use metrics, logs, and visualizations to gain creative and analytical insight into the structure, growth, and coherence of understanding.
