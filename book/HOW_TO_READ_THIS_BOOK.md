
\noindent\textbf{\Large How to Read This Book}

This book is a story about tools, physical, symbolic, and computational, and about the ways they shape how we understand the world. It is not a textbook, and it is not a technical manual. It is a path through a landscape.

You can read it straight through, or you can treat it as a set of walkable structures. Some chapters are historical, some are conceptual, and some are executable. All of them are meant to be inhabited, not memorized.

If you want to explore the programs, lineage diagrams, or metrics that accompany the book, the repository contains the larger supporting structure. But nothing in the book requires that you do so.

This is a human story first.
